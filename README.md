# Доминион для Owlbear Rodeo

Текущая версия 0.3.1. Расширение для пробного матча 6×6 в Owlbear Rodeo, опубликовано на GitHub Pages.

Манифест для установки — https://dem-mort.github.io/dominion-owlbear/manifest.json

В комнате откройте «Доминион», выберите свободную фишку. Ведущий нажимает «Начать матч». Для одиночной проверки есть кнопка «Попробовать одному за К1», затем «Отправить учебного соперника к Капле». Учебный С1 начинает на синем респе, идёт к Капле и выбирает приём в каждом раунде. После старта кнопки Трефа, Капля и Звезда задают цель движения. Инструмент «Бег» позволяет указать произвольную цель на карте.

Во время матча союзники видны на всей карте. Противник появляется в пределах 72 единиц карты от собственной живой фишки, что соответствует диаметру круга захвата. При удалении он исчезает. Игрок на респе не обнаруживает противников. Ведущий, занявший фишку, получает такое же ограничение. Ведущий без фишки видит всех участников. Это визуальное ограничение через локальные объекты Owlbear. Общее состояние фишек остаётся доступно расширению.

Все участники начинают на респе своей команды. После смерти фишка возвращается на этот же респ и ждёт 25 секунд до возрождения. До конца отсчёта двигаться нельзя.

Матч длится 12 минут или до 1000 очков. Захват, очки, бафы, стычки и респ считаются автоматически. Скорость пробного матча соответствует 10 секундам от красного респа до центра Капли. Для приближения к игре нужно измерить этот путь в клиенте и указать время перед стартом. Движение идёт по прямой.

Бой начинается при встрече обеих команд в круге точки или места питомца. Панель участника открывается автоматически. Бой состоит из трёх раундов по 5 секунд. Один приём за раунд, первый принятый выбор фиксируется. Быстрота и число кликов не увеличивают результат. Выбор противника не отображается до конца раунда.

Блок побеждает удар, обман побеждает блок, удар побеждает обман. Каждый сыгранный раунд приносит команде d6 +2 за действие. Удачный приём даёт ещё +2. В групповом бою сравниваются выбранные приёмы всех участвующих врагов, бонус даётся, если выигранных сравнений больше проигранных. Не выбравшие приём не получают броска и приносят 0. Сумма трёх раундов определяет победителя. Равенство решается перебросом d6.

Игрок, который остался на месте боя и за полный бой не сыграл ни одного раунда, погибает независимо от победы союзников. Все оставшиеся на месте участники проигравшей команды возвращаются на респ. Можно отступить обычным движением, тогда вклад в незавершённый раунд теряется. Подкрепление получает возможность выбирать приём со следующего полного раунда.

Питомец забирается за 5 секунд без врагов. Первая волна в 0:30, затем каждые 120 секунд. У носителя есть один заряд на бой. В первом сыгранном раунде заряд расходуется, после чего владелец получает +2 за каждый свой сыгранный раунд этого боя, максимум +6 за три раунда. На пропущенный раунд бонус не даётся. У разных носителей бонусы считаются отдельно. Питомец не спасает от поражения без действий. Бой за место питомца идёт и во время КД, получение бафа возможно только после его появления.

Памятка справа на карте обновляется локальным SVG поверх исходной картинки. Оригинал карты не публикуется и не меняется. После выхода из тренировки учебные имена очищаются. Расчёт движения идёт каждые 100 мс, отправка общих объектов и целей перетаскивания ограничена интервалом 400 мс, чтобы не превышать частоту запросов Owlbear.

Для разработки запустите `node --test verify.test.mjs`. Проверки включают видимость, движение, захват, очки, бафы, бой на точке и питомце, пропуски действий, одинаковый результат раннего и позднего выбора, спам, подмену чужого выбора и учебного соперника. Сборка GitHub Pages выполняется командой `node build-pages.mjs`, результат находится в `dist/pages`. В публикацию входят код и значки расширения. Карта и данные комнаты в сборку не входят. Это настольная адаптация боя. Калибровка скорости по игре и живой прогон с 12 людьми остаются отдельными проверками.
