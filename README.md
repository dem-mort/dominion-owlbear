# Доминион для Owlbear Rodeo

Текущая версия 0.2.1. Расширение опубликовано на GitHub Pages.

Манифест для установки — https://dem-mort.github.io/dominion-owlbear/manifest.json

В комнате откройте «Доминион», выберите свободную фишку. Ведущий нажимает «Начать матч». Для одиночной проверки есть кнопка «Попробовать одному за К1». После старта кнопки Трефа, Капля и Звезда задают цель движения. Инструмент «Бег» позволяет указать произвольную цель на карте.

Во время матча союзники видны на всей карте. Противник появляется в пределах 72 единиц карты от собственной живой фишки, что соответствует диаметру круга захвата. При удалении он исчезает. Игрок на респе не обнаруживает противников. Ведущий, занявший фишку, получает такое же ограничение. Ведущий без фишки видит всех участников. Это визуальное ограничение через локальные объекты Owlbear. Общее состояние фишек остаётся доступно расширению.

Все участники начинают на респе своей команды. После смерти фишка возвращается на этот же респ и ждёт 25 секунд до возрождения. До конца отсчёта двигаться нельзя.

Матч длится 12 минут или до 1000 очков. Захват, очки, бафы, стычки и респ считаются автоматически. Скорость пробного матча соответствует 10 секундам от красного респа до центра Капли. Для приближения к игре нужно измерить этот путь в клиенте и указать время перед стартом. Движение идёт по прямой.

На живой проверке 0.2.0 в двух вкладках подтверждены скрытие далёкого противника, появление при встрече и возврат проигравшего на респ. Обнаружен `RateLimitHit` при частой отправке координат. В 0.2.1 расчёт движения идёт каждые 100 мс, отправка общих объектов и целей перетаскивания ограничена интервалом 400 мс. Из обновления общих объектов убран повторный запрос `getItems`.

Локальные проверки включают движение, захват, очки, бафы, стычку, респ, отдельные виды двух клиентов, границу видимости и восстановление фишек в лобби. Для разработки запустите `node --test verify.test.mjs`. Сборка GitHub Pages выполняется командой `node build-pages.mjs`, результат находится в `dist/pages`. В публикацию входят код и значки расширения. Карта и данные комнаты в сборку не входят.
